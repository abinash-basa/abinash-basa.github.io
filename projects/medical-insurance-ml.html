Medical Insurance Cost Prediction with Machine Learning

Evaluating statistical tests (ANOVA, Pearson correlation) and five regression models across 1,338 records to identify key drivers of individual healthcare charges.

Project Type M.Sc. Mathematics Dissertation
Top Result Gradient Boosting (R² = 0.878)
Dataset 1,338 Records, 7 Variables
Tools Python, Scikit-learn, SciPy, Pandas
Overview & Problem Statistical Analysis Model Benchmark Key Findings Dissertation PDF

Overview and Problem Statement

Accurate healthcare cost prediction is essential for insurance pricing and risk assessment. Traditional linear pricing models often struggle to account for compounding health risks, such as the interaction between high body mass index (BMI) and smoking habits.

This dissertation explores how combining exploratory data analysis, hypothesis testing, and machine learning models can improve cost predictions on individual medical expense data.

Statistical Analysis and Variables

The study analyzed the Medical Cost Personal Dataset (1,338 records, 7 variables: age, sex, bmi, children, smoker, region, and charges).

Key Statistical Findings

Two-sample t-tests and one-way ANOVA showed that smoking status (p < 0.001) and BMI categories are the primary drivers of high charges, while biological sex and geographical region had minimal direct impact on price variations.

Model Evaluation and Comparison

Five supervised regression algorithms were evaluated using an 80/20 train-test split on standardized metrics: R², Root Mean Squared Error (RMSE), and Mean Absolute Error (MAE):

  • Gradient Boosting Regressor: Best overall performance (R² = 0.878), effectively capturing the non-linear interaction between BMI and smoking status.
  • Random Forest Regressor: Second best performer (R² ~ 0.861), showing steady generalization across cross-validation folds.
  • Multiple Linear Regression (OLS): Provided a transparent baseline (R² ~ 0.750) but under-predicted high-cost outliers.
  • Decision Tree Regressor: Showed higher variance and local overfitting (R² ~ 0.730).
  • Support Vector Regression (SVR): Sensitive to kernel parameter choices on non-linear price curves.

Key Findings

The results show that linear models consistently under-price risk for smokers with high BMI because risk multiplies rather than adds linearly. Using tree-based ensemble models like Gradient Boosting allows pricing models to better reflect these combined risks.
