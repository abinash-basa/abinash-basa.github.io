Spotify to YouTube Music Playlist Migration Tool

A Python command-line tool that syncs playlist libraries from Spotify to YouTube Music with OAuth 2.0 authentication, rate limit resilience, and fuzzy metadata track matching.

Type Open Source Automation Tool
Language Python 3
APIs Spotify Web API, YouTube Data API v3
Code github.com/abinash-basa
Overview & Problem Pipeline & OAuth Track Matching Rate Limiting Key Learnings

Overview and Problem Statement

Moving music libraries from Spotify to YouTube Music manually takes hours. Existing third-party web services often require paid subscriptions, have strict song limits, or struggle with track title discrepancies (such as remasters, featured artist labels, or live versions).

I built this Python tool to automate the entire transfer process for personal use without third-party fees.

Workflow and OAuth Setup

The tool runs through three main steps:

1. Dual OAuth 2.0 Authentication

Authenticates with Spotify to read user playlists and with Google to write playlists to YouTube Music, managing token refreshes automatically.

2. Metadata Extraction and Cleaning

Fetches track titles, primary artists, and album names from Spotify, stripping noise like "(Remastered 2011)" or "(feat. ...)" to improve search hit rates.

3. Playlist Creation and Batch Insert

Creates the target playlist on YouTube Music, searches for the best matching video ID for each track, and inserts the songs in batches.

Fuzzy Track Matching

YouTube's search catalog includes official tracks alongside lyric videos, covers, and live recordings.

To pick the right track, the search module runs a multi-pass check:

  • Pass 1: Direct match against Official Audio / Topic channel uploads.
  • Pass 2: Levenshtein string distance on Artist and Track Title.
  • Pass 3: Duration verification within 5% of the original track duration.

Quota and Rate Limiting

The YouTube Data API has a default daily quota of 10,000 units. Adding a song consumes 50 units. The script includes exponential backoff for rate limits and saves progress locally so that if a migration is paused or hits a limit, it can resume without creating duplicate tracks.

Key Learnings

  • API Limits: Designing for rate limits and token expirations from day one prevents unexpected crashes during long transfers.
  • Data Cleaning: Normalizing track titles before searching drastically increases match accuracy.
  • Clear Feedback: Printing a summary of unmapped songs allows users to quickly review and add any missing tracks manually.
