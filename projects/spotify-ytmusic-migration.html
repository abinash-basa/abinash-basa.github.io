Spotify to YouTube Music Migration Engine

An automated library synchronization engine built to transfer user playlists across streaming platforms with OAuth2 multi-token flows and fuzzy track resolution heuristics.

Language Python
APIs Spotify Web API, YouTube v3
Security OAuth 2.0 PKCE / User Auth
Key Challenge Fuzzy Matching and Quota Limits
Contents Overview and Problem System Architecture Matching Heuristics Quota and Rate Resilience Key Takeaways

Overview and Problem Statement

Users frequently maintain curated music collections on Spotify but face substantial manual friction when migrating to YouTube Music. Existing commercial tools often impose restrictive paywalls or fail to resolve subtle track metadata discrepancies (remixes, live versions, remaster tags).

This project was created as an automated, developer-friendly synchronization utility that extracts playlist data from Spotify and reconstructs identical playlist schemas on YouTube Music.

System Architecture and Workflow

The migration engine operates in a multi-stage sequential pipeline:

1. Dual OAuth 2.0 Authentication

Acquires read access tokens from Spotify and write permissions for YouTube Data API v3, managing token refresh cycles securely in memory.

2. Metadata Extraction and Cleaning

Paginates through Spotify user playlists, extracting track names, primary artists, album titles, and ISRC codes while stripping clutter terms (e.g., "- 2011 Remaster", "(feat. ...)").

3. Automated Playlist Construction

Creates matching playlists on YouTube Music and batch-inserts identified video track IDs, logging any unresolvable items for manual review.

Fuzzy Track Matching Heuristics

YouTube's search index is significantly noisier than structured streaming catalogs due to user-uploaded covers, lyric videos, and live audio.

To ensure high matching fidelity, the search module applies a multi-pass ranking heuristic:

  • Pass 1: Exact match on Official Audio / Topic channel uploads.
  • Pass 2: Levenshtein string distance thresholding on `Artist + Track Title`.
  • Pass 3: Duration tolerance verification within ±5% of the original track duration.

Quota and Rate-Limiting Resilience

The YouTube Data API enforces strict daily quota budgets (10,000 units/day, where playlist insert operations consume 50 units). The script incorporates exponential backoff, rate throttling, and idempotent checkpointing so interrupted migrations can resume without duplicating already-inserted tracks.

Key Takeaways and Product Thinking

  • API Edge Cases: Real-world integration requires robust handling of rate limits, expired tokens, and catalog divergences.
  • Data Hygiene: Upstream text normalization directly dictates downstream search accuracy in unstructured catalog indices.
  • Graceful Degradation: Clear CLI logs and fallback unmapped-track reports ensure users remain in complete control.
